# 🏥 위드케어 (WithCare) - 대전 의료전공 대학생 병원 동행서비스 (v3.3)

> **대전광역시 MVP 모델 · 대학교 수업 프로젝트 발표 및 시연용 웹 애플리케이션**  
> *"부모님 병원 가는 길, 근처 동행 매니저와 신속하게"*

## 🌟 최신 개편 사항 (v3.3)

1. **📸 고령층 환자와 동행하는 대학생 Hero 이미지 교체**
   - 텍스트가 인쇄되어 있던 이전 시안 배경을 삭제하고, **고령층 환자와 다정하게 동행하는 청년 케어기버 고화질 사진**으로 교체
   - 간결한 2개 버튼: **`[동행자 찾기]`** (밝은 버튼) / **`[예약하기]`** (어두운 버튼)

2. **🗺️ GPS 기반 지도 인터랙티브 뷰 탑재 (동행자 찾기)**
   - 대전광역시 주요 권역(서구, 유성구, 중구 등)과 도로망, 강줄기(갑천)가 그려진 **GPS 관제 지도 캔버스** 구현
   - **내 현재 위치 핀 (펄싱 레이더 링)** 및 **대학생 동행자 위치 핀 (아바타 + 도보 소요시간 뱃지)** 시각화
   - **지도 위 동행자 핀을 클릭하면** 우측에 해당 동행자의 상세 프로필, 자격, 소요 시간, 소개글, **`[이 동행자와 바로 예약하기]`** 버튼이 즉시 연동되어 표시

3. **👤 네비게이션 '마이페이지' 단일 메뉴 통합 & 로그인 간소화**
   - `이용자 페이지`와 `동행자 페이지`를 하나의 **`[마이페이지]`**로 통합
   - 로그인된 권한에 따라 자동으로 맞춤 페이지 렌더링:
     * **이용자(환자/보호자) 로그인 시** ➜ 실시간 5단계 프로세스 트래커, 환자 기본정보 관리, 1:1 대화방
     * **동행자(의료 전공 대학생) 로그인 시** ➜ 봉사시간 대시보드, 1365/VMS 확인서 미리보기, 실시간 긴급 환자 요청 수락
   - 로그인 시연용 대학생 동행자를 대표 1인 **'김서연 (충남대 간호학과 3학년)'**으로 단일화하여 원클릭으로 간편하게 시연 가능
