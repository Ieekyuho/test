# 🏥 위드케어 (WithCare) - 부모님 병원 동행서비스 매칭 플랫폼 MVP
> **대학교 수업 프로젝트 발표 및 시연용 풀스택 웹 애플리케이션**  
> *"부모님 병원 가는 날, 든든한 전문 동행 매니저를 만나보세요"*

---

## 🌟 1. 프로젝트 개요 (Project Overview)

고령화 사회 진입에 따라 급증하는 **노년층 외래 진료 동행 수요**와 직장 업무로 직접 동행하기 어려운 **3040 자녀(보호자)의 페인 포인트**를 해결하기 위한 의료 복지 매칭 플랫폼입니다.

실제 결제나 외부 복잡한 API 연동 없이도, 핵심 유저 플로우(**AI 증상 기반 병원 추천 ➜ 예약 신청 ➜ 매칭 및 5단계 실시간 진행 ➜ 안심 리포트 및 별점 리뷰**)를 교수님 및 평가위원 앞에서 완벽하게 시연할 수 있도록 기획·구현되었습니다.

---

## 🚀 2. 핵심 기능 및 구현 페이지 안내

### 1) 랜딩 페이지 (Landing Page - Home)
- **Hero Section**: 신뢰감을 주는 헤드카피와 [간편 예약하기], [AI 증상 기반 병원 추천] CTA 버튼
- **신뢰 지표 요약**: 누적 안심 동행 14,280+건, 만족도 99.4%, 전문 자격증 검증 100%
- **3대 안심 기준 카드**:
  1. **자격증 100% 검증 매니저** (간호사, 간호조무사, 요양보호사 1급, 사회복지사 전수 검증)
  2. **실시간 5단계 안심 리포트** (픽업부터 진료, 처방약 수령, 귀가까지 실시간 알림)
  3. **1:1 맞춤 전담 동행 케어** (어르신 거동 상태 맞춤, 휠체어 전용 보조, 수납 대행)
- **AI 증상 분석 맛보기 위젯**: 다리 저림, 가슴 답답 등 자주 묻는 주요 증상 원클릭 테스트
- **B2B 비즈니스 모델 요약 카드**: 중개수수료 외 병원 타겟 광고 및 제휴 마케팅을 통한 추가 수익화 전략
- **검증된 전문 매니저 쇼케이스**: 실시간 평점 및 자격증 정보 카드
- **보호자 실제 생생 이용 후기**: 직장인 자녀들의 생생한 별점 5점 리뷰

### 2) AI 증상 분석 및 병원 추천 (AI Symptom & Hospital Finder)
- **자연어 증상 입력창**: "어머니가 자꾸 다리가 저리고 걷기 힘드셔", "가슴이 답답하고 숨이 차요" 등 일상 언어로 입력 가능
- **인공지능 의료 모델 분석 시뮬레이션**: 증상 맥락 분석 ➜ 의심 질환군 및 권장 진료과(정형외과, 순환기내과, 안과, 신경과 등) 도출
- **추천 전문 및 제휴 병원 리스트**: 병원명, 진료과, 거리, 전문의 수, 보건복지부 인증 마크, B2B 제휴 패스트트랙 혜택 배지
- **[이 병원으로 동행 예약하기] 버튼**: 클릭 즉시 [동행 예약 신청 폼]으로 병원명과 진료과가 자동 입력(Prefill)되어 유기적으로 연동!

### 3) 동행 예약 신청 페이지 (Booking Flow)
- **단일 스크롤 폼(Single Scroll Form)**: 단계별 번호와 함께 매끄러운 입력 경험 제공
  * **환자 정보**: 성함, 연령, 성별, 환자 연락처, 신청 보호자 연락처
  * **거동 상태 선택 (3대 시각 카드)**: 
    - ① 혼자 보행 가능 (기본 요율)
    - ② 거동 불편 · 부축 필요 (+10,000원)
    - ③ 휠체어 이용 필수 (+20,000원)
  * **병원 일정**: 병원명(AI 연동 및 퀵 버튼), 진료과 선택, 날짜(달력 인터페이스), 시간 슬롯(09:30~16:30)
  * **동행 옵션**: 자택 픽업 주소(샘플 주소 채우기 지원), 서비스 시간(2시간/3시간/4시간), 약국 조제 수령 대행(+10,000원), 원내 수납 대행(무료), 휠체어 대여(+10,000원)
  * **매니저 전달 메모**: 청각 보조, 상세 진료 메모 등
- **실시간 예상 견적 계산 박스**: 옵션 선택에 따라 기본료, 거동 지원금, 약국 수령비가 실시간 자동 합산되어 투명하게 표시
- **[동행 예약 신청 완료]**: 클릭 시 인메모리/로컬 DB에 저장되고 즉시 대시보드로 이동

### 4) 실시간 예약 관리 & 대시보드 (Dashboard & Progress Tracker)
- **상태별 탭 필터링**: `[전체]` / `[예약 대기중]` / `[매칭 및 진행중]` / `[동행 완료]`
- **실시간 5단계 상태 트래커 (Progress Bar)**:
  ① 예약 완료 ➜ ② 매니저 배정 ➜ ③ 자택 픽업 ➜ ④ 병원 진료 중 ➜ ⑤ 귀가 완료
  * 현재 단계에 펄싱(Pulsing) 애니메이션과 명확한 상태 설명 표시
- **배정된 테스트 매니저 프로필 카드**: 사진, 이름, 요양보호사 1급 인증 마크, 평점(4.98), 연락처, 소개글
- **🎓 발표 시연용 컨트롤러**: `[다음 단계로 진행 시연 (Demo Next Step)]` 버튼을 통해 심사위원 앞에서 단계 전환을 즉각 시연 가능

### 5) 안심 리포트 및 완료 페이지 (Report & Review)
- **진료 결과 요약 박스**: 전문의 진료 소견, X-ray/검사 결과, 의사 상담 내용
- **다음 재진 예약일 & 처방 약 수령 박스**: 재진 일자 강조, 복약 지도 내용
- **당일 건강 상태 & 매니저 안심 메시지**: 어르신 컨디션 보고
- **실시간 이동 타임라인 로그**: 09:00 자택 픽업 ➜ 09:25 병원 접수 ➜ 10:15 진료실 ➜ 11:10 약국 ➜ 12:15 안전 귀가
- **증빙 사진 갤러리 Mockup**: 처방전, 진료비 영수증, 안심 귀가 사진
- **보호자 별점 및 한줄평 리뷰 UI**: 5점 만점 별 클릭, 칭찬 키워드 태그, 감사평 입력 후 실시간 등록

### 6) 권한별 듀얼 모드 (보호자 모드 ↔ 동행 매니저 모드)
- 상단 네비게이션 우측에서 **원클릭으로 자유롭게 역할 전환**
- **[동행 매니저 모드]**:
  * 들어온 예약 요청 리스트를 확인하고 **[예약 수락]** 버튼 클릭 시 즉시 매칭 완료
  * 단계 진행(자택 픽업 ➜ 병원 진료 ➜ 귀가 완료)을 직접 조작
  * **[진료 결과 안심 리포트 작성]** 모달에서 의사 소견과 처방 내용을 직접 입력·저장
- **데이터 실시간 공유**:
  * 보호자가 신청한 예약이 매니저 모드 리스트에 즉시 반영
  * 매니저가 수락하고 작성한 리포트가 보호자 모드에 실시간 반영 (동일 브라우저 탭 및 멀티 탭 자동 동기화 지원)

### 7) B2B 비즈니스 모델 (추가 수익화 전략)
- **병원 타겟 광고 & 제휴 마케팅**: AI 증상 분석 시 제휴 전문병원 상단 노출 및 CPC/월정액 광고료
- **병원 공식 파트너십 패스트트랙**: 외래 접수/수납 우선 창구 운영 제휴 수수료
- **기업 임직원 부모님 케어 B2B 구독**: 사내 복지 포인트 연동 정기 동행 패키지
- **지자체 어르신 돌봄 통합지원 바우처**: 정부 및 지자체 공공 복지 조달 사업 연계

## 💻 4. 기술 스택 및 구조

- **Frontend**: React 18 (Standalone Hooks & Component Architecture), Tailwind CSS (반응형 모바일/태블릿/데스크톱 대응)
- **UI & Icons**: 자체 인라인 SVG 아이콘 팩 (외부 네트워크 지연 없는 즉각 렌더링)
- **State & DB**: `WithCareStoreManager` (In-Memory State + LocalStorage 영속화 + Cross-tab Storage 이벤트 실시간 동기화)
- **Typography**: Pretendard (국내 최적화 가독성 폰트)
- **배포 및 실행**: 별도의 Node.js 설치나 복잡한 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 Chrome, Edge 등 모든 모던 웹 브라우저에서 100% 즉시 실행 가능합니다.

## 📁 5. 파일 디렉터리 구성

- **`index.html`**: 시맨틱 웹 마크업, 반응형 뷰포트, Tailwind CDN, React 18 및 Babel 로더
- **`data.js`**: 사전 검증된 전문 매니저 목록, 대기/진행/완료 더미 예약 3건, AI 증상 분석 지식베이스, 추천 병원 DB, 보호자 후기
- **`store.js`**: 인메모리 & 로컬스토리지 연동 상태 관리자 (예약 생성, 매니저 수락, 상태 단계 전진, 리포트 저장, 리뷰 등록, 초기화)
- **`app.js`**: 헤더, 모드 스위처, 4개 핵심 페이지(홈, AI 병원 찾기, 예약 폼, 대시보드), 안심 리포트 모달, B2B 모달 등 전체 React 애플리케이션
- **`style.css`**: 스크롤바 미려화 및 인쇄 최적화 스타일
- **`SPECIFICATION.md`**: 상세 기능 요구사항 및 아키텍처 명세서
- **`README.md`**: 본 프로젝트 안내서
