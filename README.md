# 🏥 위드케어 (WithCare) - 부모님 병원 동행서비스 매칭 플랫폼 (v3.1)

> **대학교 수업 프로젝트 발표 및 시연용 풀스택 웹 애플리케이션 (MVP)**  
> 복잡한 외부 백엔드 설치 없이, **웹 브라우저에서 `index.html`을 더블클릭하거나 경량 서버로 즉시 구동**할 수 있습니다.

---

## 🌟 주요 기능 및 최신 업데이트 (v3.1)

1. **⏱️ 실시간 5단계 동행 프로세스 트래커 복원 및 고도화**
   - **5단계 원형 스텝퍼**: `① 예약 완료` ➜ `② 매니저 배정` ➜ `③ 자택 픽업` ➜ `④ 병원 진료 중` ➜ `⑤ 귀가 완료`
   - **단계별 세부 설명 박스**: 각 단계가 바뀔 때마다 전문 동행 매니저의 케어 활동 세부 설명(`stepDetail`)이 상세 브리핑 박스로 동적 갱신
   - **실시간 위치 및 상태 표기**: GPS 없이도 실시간 위치(`locationText`) 및 남은 시간(`eta`) 명확 표기
   - **발표 시연용 진행 버튼**: `[다음 단계로 진행 시연 (➜ N단계)]` 버튼을 통해 시연 시 라이브로 상태와 세부 설명 전환 확인 가능

2. **👤 환자 마이페이지 기능 완성**
   - **환자 기본 정보 관리 (조회 및 실시간 수정)**: 성함, 생년월일, 연락처, 주소, 질환/증상, 복용약, 기본 메모를 저장하면 신규 예약 시 자동 입력
   - **4열 핵심 정보 카드**: 예약번호, 일시, 상태 배지, 환자/거동상태, 병원/진료과, 일시, 픽업지/견적
   - **축소 내장형 AI 추천 매니저**: 마이페이지 내부에서 환자 증상 맞춤 매니저 2인을 추천받아 즉시 예약 가능

3. **🔐 역할별 전용 로그인 및 권한 분기**
   - 상단 모드 전환 토글을 제거하고 정식 로그인 체계 구축
   - **[환자/보호자 로그인]**: 회원 및 비회원(성함, 생년월일, 4자리 비밀번호) 로그인 지원
   - **[동행 매니저 로그인]**: 검증된 전문 매니저 계정으로 접속하여 업무 관리, 예약 수락, 위치 전진, 리포트 작성 수행

4. **💬 1:1 안심 실시간 대화방 & 📋 진료 결과 안심 리포트**
   - 보호자와 담당 매니저 간의 실시간 메시지 소통
   - 진료 핵심 AI 음성 녹음 요약본 및 전문 진료 소견, 복약 지도 안내 제공
   - 프리미엄 심층 건강 리포트(자물쇠 잠금 UI)로 비즈니스 모델(BM) 시연 지원

## 🚀 실행 방법 (2가지 중 택 1)

### 방법 1. 웹 브라우저에서 직접 실행 (무설치, 가장 간단)
- `index.html` 파일을 더블클릭하여 Chrome, Edge 등의 브라우저에서 바로 엽니다.
- (Babel 인라인 번들링이 완료되어 로컬 파일(`file:///`) 환경에서도 CORS 오류 없이 100% 정상 작동합니다.)

### 방법 2. 초경량 로컬 웹 서버로 실행
1. 터미널 또는 명령 프롬프트에서 프로젝트 폴더로 이동합니다:
   ```bash
   cd c:\Users\82103\Downloads\mypage
   ```
2. 서버를 구동합니다:
   ```bash
   node server.js
   ```
3. 브라우저에서 아래 주소로 접속합니다:
   ```
   http://localhost:3000
   ```
*(또는 폴더 내의 `웹서버실행.bat`을 더블클릭해도 자동으로 서버가 시작됩니다.)*

## 📁 주요 파일 구성
- `index.html`: 서비스 메인 페이지 (React + Tailwind CSS 인라인 번들링 완성본)
- `app.js`: React 메인 애플리케이션 컴포넌트 소스코드
- `data.js`: 환자 프로필, 검증 매니저 4인, 제휴 병원, 5단계 트래킹 메타 및 세부 설명 데이터셋
- `store.js`: 브라우저 LocalStorage 기반 반응형 가상 데이터베이스
- `server.js`: Node.js 내장 http 모듈 기반 무설치 로컬 웹 서버
- `build.js`: `app.js`를 `index.html`로 패키징하는 인라인 번들러 스크립트
- `SPECIFICATION.md`: 상세 기능 명세서
