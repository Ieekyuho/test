> **대학교 수업 프로젝트 발표 및 시연용 풀스택 웹 애플리케이션**  
> *"부모님 병원 가는 날, 든든한 전문 동행 매니저를 만나보세요"*

## 🌟 1. 주요 업데이트 및 신규 기능 (v2.0)

사용자 피드백을 반영하여 **발표 및 시연 효과를 극대화할 수 있는 핵심 모듈 5종**을 신규 구축 및 개편하였습니다:

1. **로그인 및 권한별 마이페이지 분기**:
   - **회원 / 비회원 로그인**: 비회원 로그인 시 (성함, 생년월일, 4자리 비밀번호) 입력 기능 제공
   - **[환자/보호자 로그인]과 [매니저 로그인] 완벽 분리** 및 상단 즉시 전환 모드
2. **매니저 인재 검증 시스템 (Trust & Verification) & AI 추천**:
   - 매니저 프로필 상단에 **3대 인재검증 인증 마크** 표시 (자격증 100% 검증, 심층 면접 통과, 40시간 필수 보건교육)
   - 환자 증상/거동에 최적화된 **상단 AI 매니저 추천 (AI PICK TOP 2)**
   - 상세 조건 필터링 바 (성별, 지역, 자격증, 운전면허 소지 여부)
3. **환자 정보 폼 & 개별 의견란 분리 & 이동수단 3종**:
   - 생년월일, 거주 지역, 증상 정리, 복용약, 휠체어 이용 여부
   - **개별 의견란 분리**: ① "의사에게 하고 싶은 말", ② "매니저에게 하고 싶은 말"
   - **이동 수단 3가지 옵션**: ① 택시/대중교통, ② 매니저 자차 동행, ③ 도보 동행
   - **구급차 지원 제외 안내 문구 필수 명시**
   - 병원 카드 UI: **외관 실사 사진**, **GPS 지도 썸네일**, **자차 소요 시간(차로 15분)**, **전문 진료과**
4. **동행 진행 단계 (Live Tracking & Chat)**:
   - **배달의민족 스타일 실시간 라이브 트래커 (더미 시뮬레이션)**: 매니저 이동 핀 및 도착 8분 전 실시간 상태 안내
   - **카카오톡 스타일 1:1 실시간 채팅 모듈**: 노란 테마, 말풍선, 퀵 메시지, 보호자 ⇄ 매니저 시점 실시간 전환
5. **동행 후 리포트 및 평가 단계 (마이페이지)**:
   - **진료실 AI 음성 녹음본 요약 뷰 (시뮬레이션)**: 가상 오디오 파형 웨이브, 핵심 3대 불렛 포인트
   - **매니저 직접 입력 진료 결과**: 처방약 복용법 상세 안내
   - **리포트 등급별 잠금 (수익화 시뮬레이션 B2B/B2C 프리미엄 BM)**: 자물쇠 UI & 잠금 해제 체험
   - **동행 종료 만족도 평가**: 제출된 별점이 **해당 매니저의 프로필 평점에 실시간으로 즉시 연동 반영**

## 🎬 2. 추천 발표 시연 시나리오 (Demo Runbook)

```
[1단계] 로그인 분기 시연
  - 상단 [로그인] 버튼 클릭 ➜ [비회원 간편 로그인] 탭 선택
  - 이름(홍길동), 생년월일, 비밀번호(1234) 입력 후 비회원 마이페이지 진입 시연

[2단계] 매니저 탐색 & 인재검증 시스템 확인
  - 상단 메뉴 [매니저 탐색 & AI 추천] 이동
  - 상단 'AI PICK TOP 2' 매니저 카드 확인 (자격증, 심층면접, 40시간 교육 3대 마크)
  - 필터에서 '자차 운행 가능 매니저' 체크 ➜ 김서연 매니저 카드에서 [이 매니저에게 동행 신청] 클릭!

[3단계] 예약 폼 작성 & 이동수단 & 개별 의견란
  - 환자 생년월일, 복용약(혈압약), 휠체어 이용 여부 체크
  - [의사에게 하고 싶은 말]과 [매니저에게 하고 싶은 말]이 분리된 폼 작성
  - 이동 수단 중 [매니저 자차 동행] 선택 ➜ 실시간 견적 자동 반영 확인
  - '구급차 지원 제외 안내 문구' 확인 후 [동행 예약 신청 완료] 클릭!

[4단계] 매니저 모드 수락 & 배민 라이브 트래커 시연
  - 상단 우측 스위치에서 [🩺 동행 매니저] 클릭 ➜ [이 예약 즉시 수락하기] 클릭
  - [다음 위치 단계로 시뮬레이션] 버튼을 눌러 "자택으로 출발 (8분 전)" ➜ "자택 앞 도착" ➜ "병원 이동 중" 진행 시연

[5단계] 카카오톡 1:1 실시간 대화방 시연
  - [1:1 카카오톡 대화방 열기] 클릭
  - 노란 카카오톡 채팅방에서 "자택 앞 5분 전 도착 예정입니다!" 퀵 메시지 전송
  - 상단 '시점: 매니저 ⇄ 보호자' 칩을 눌러 보호자 시점으로 전환 후 실시간 수신 및 답장 연출

[6단계] AI 음성 요약 & 프리미엄 잠금 BM & 만족도 평가
  - 5단계 완료 후 [안심 리포트 & AI 음성요약 열람] 클릭
  - AI 음성 녹음 오디오 파형과 핵심 3포인트 요약 확인
  - [심층 건강 리포트 잠금] UI 확인 및 [🔓 잠금 해제 토글] 버튼으로 프리미엄 BM 설명
  - 하단에서 별점 5점과 감사 후기 등록 ➜ 해당 매니저의 평점과 리뷰 수가 즉시 올라가는 실시간 연동 확인!
```

## 📁 3. 파일 디렉터리 구성

- **`index.html`**: 메인 웹 애플리케이션 진입점 (React 18 + Babel 번들링, 더블클릭 실행 시 CORS 오류 원천 차단)
- **`app.js`**: React 18 메인 컴포넌트, 로그인 모달, 매니저 탐색, 예약 폼, 배민 트래커, 카톡 모듈, 리포트 모달
- **`data.js`**: 인재검증 매니저 5인, 이동수단, 병원 외관사진/주행시간, 더미 카톡내역, AI 음성요약
- **`store.js`**: 로그인 세션, 예약 상태, 카톡 채팅, 매니저 평점 실시간 갱신, 로컬스토리지 동기화
- **`icons.js`**: 20종 내장 인라인 SVG 아이콘 팩
- **`실행하기.bat`**: 더블클릭 시 기본 브라우저에서 `index.html`을 바로 띄우는 1초 실행 스크립트
- **`SPECIFICATION.md`**: 제출용 상세 기능 명세서
- **`README.md`**: 본 프로젝트 안내서
