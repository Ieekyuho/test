# 🏥 위드케어 (WithCare) - 부모님 병원 동행서비스 매칭 플랫폼 v3.0
> **대학교 수업 프로젝트 발표 및 시연용 웹 애플리케이션**  
> *"부모님 병원 가는 날, 든든한 전문 동행 매니저를 만나보세요"*

---

## 🌟 1. 최신 수정사항 반영 안내 (v3.0)

1. **표현 정돈**:
   - '배민 스타일' 표현을 제거하고 **'실시간 동행 위치 안내' / '실시간 안심 위치 트래커'**로 깔끔하게 변경
   - '카카오톡' 표현을 제거하고 **'1:1 안심 실시간 대화방'**으로 단정하게 통일
2. **환자 마이페이지 기능 강화**:
   - 환자 마이페이지에 **환자 기본 건강 정보 관리(조회 및 수정 폼)** 추가 (성함, 생년월일, 연락처, 자택 주소, 평소 주요 증상, 정기 복용약, 휠체어 여부 직접 입력 및 저장)
   - 저장된 정보는 다음 동행 예약 신청 폼에 자동 입력 연동
3. **AI 매니저 추천 기능 축소 & 환자 마이페이지 내장**:
   - 상단 대메뉴에서 별도 분리하지 않고, **환자 마이페이지 내부의 서브탭/섹션으로 콤팩트하게 내장**
4. **화면 전환 토글 삭제 ➜ 직관적인 로그인/권한 체계로 일원화**:
   - 상단에 있던 어색한 '보호자 ⇄ 매니저 화면 전환 토글'을 완전히 삭제
   - **[환자/보호자 로그인]** (기존 회원 / 비회원 간편 로그인: 성함, 생년월일, 4자리 비밀번호)과 **[동행 매니저 로그인]** (활동 매니저 선택)으로 완벽 분기
   - 로그인된 역할에 따라 마이페이지가 **환자 마이페이지** 또는 **매니저 마이페이지**로 직관적으로 자동 분기
5. **UI/UX 직관성 향상**:
   - 상단 네비게이션을 `서비스 소개`, `AI 병원 찾기`, `동행 예약 신청`, `마이페이지`로 단순화하여 사용성 극대화

## 🎬 2. 추천 발표 시연 시나리오 (Demo Runbook)

```
[1단계] 로그인 분기 시연
  - 상단 [로그인/본인인증] 클릭 ➜ [환자/보호자 로그인] (비회원 간편 로그인: 홍길동 / 1985-05-15 / 1234)
  - 또는 [동행 매니저 로그인] ➜ 김서연 매니저 선택 후 마이페이지 자동 분기 시연

[2단계] 환자 마이페이지 & 환자 정보 관리
  - 상단 [마이페이지] 클릭 ➜ [환자 기본 정보 관리] 탭 선택
  - 환자 성함(김순자), 생년월일, 복용약, 주요 증상 수정 후 [환자 정보 저장하기] 클릭
  - [내 조건 맞춤 AI 추천 매니저] 탭에서 내장된 추천 매니저 확인

[3단계] 동행 예약 신청 폼
  - 상단 [동행 예약 신청] 이동 ➜ 방금 저장한 환자 정보가 자동 입력된 모습 확인
  - [의사에게 하고 싶은 말] & [매니저에게 하고 싶은 말] 분리 폼 작성
  - 이동 수단 3가지(택시/대중교통, 매니저 자차, 도보) 중 [매니저 자차] 선택
  - '구급차 지원 제외 안내 문구' 확인 후 [동행 예약 신청 완료] 클릭!

[4단계] 매니저 로그인 & 실시간 위치 전진
  - 상단 [전환] 클릭 ➜ [동행 매니저 로그인] (김서연 매니저)으로 전환
  - 매니저 마이페이지에서 방금 접수된 예약 확인 및 [이 예약 즉시 수락하기] 클릭
  - [위치 상태 전진] 버튼을 눌러 자택 이동 ➜ 픽업 ➜ 병원 도착 위치 갱신

[5단계] 1:1 안심 실시간 대화방
  - [보호자 1:1 대화] 클릭 ➜ 1:1 실시간 대화방 열람
  - 퀵 메시지 및 메시지 전송 시연

[6단계] AI 음성 요약 & 프리미엄 잠금 BM & 만족도 평가
  - [안심 리포트 보기] 클릭 ➜ AI 음성 녹음 핵심 요약 3포인트 확인
  - [심층 건강 리포트] 자물쇠 잠금 확인 ➜ [🔓 잠금 해제 체험]으로 유료화 BM 설명
  - 별점 5점과 후기 등록 ➜ 매니저 평점에 실시간으로 즉시 반영되는 모습 확인!
```

## 📁 3. 파일 디렉터리 구성

- **`index.html`**: 메인 웹 애플리케이션 진입점 (React 18 + Babel 번들링, 더블클릭 실행 시 CORS 오류 원천 차단)
- **`app.js`**: React 18 단일 애플리케이션 (로그인 모달, 환자 마이페이지, 매니저 마이페이지, 예약폼, 1:1 대화방, 리포트)
- **`data.js`**: 환자 기본 프로필, 매니저 4인, 이동수단, 병원 외관사진/주행시간, 대화내역, AI 음성요약
- **`store.js`**: 로그인 세션, 환자 프로필 CRUD, 예약 상태, 1:1 대화, 매니저 평점 실시간 갱신, 로컬스토리지 동기화
- **`실행하기.bat`**: 더블클릭 시 기본 브라우저에서 `index.html`을 바로 띄우는 1초 실행 스크립트
- **`SPECIFICATION.md`**: 제출용 상세 기능 명세서
- **`README.md`**: 본 프로젝트 안내서
